Notes & math

Single plate (exact)

A standard plate has 15 numbers split across 3 rows of 5 numbers each (the 3 rows share no numbers). With numbers drawn uniformly without replacement from 1–90:

P(a fixed set of m numbers all drawn within first k) = C(k, m) / C(90, m) = ∏_{i=0}^{m−1} (k−i) / (90−i)

Let p_m(k) denote the above. Using inclusion–exclusion over the 3 disjoint rows on a single plate:

  • P(≥1 row by k) = 3·p₅(k) − 3·p₁₀(k) + p₁₅(k)
  • P(≥2 rows by k) = 3·p₁₀(k) − 2·p₁₅(k)
  • P(full plate by k) = p₁₅(k)

These are exact and do not depend on the column arrangement of numbers — only on the row partition.

Multiple plates (independence approximation)

With N total plates in play, the probability that at least one plate has achieved tier T by round k is approximated as:

P(any wins T by k) ≈ 1 − (1 − p_T^single(k))^N

This assumes plates are independent, which is an approximation: real plates draw their numbers from a shared pool of 90, so there is mild positive correlation (one plate progressing tends to coincide with others progressing). The approximation is excellent when N · 15 ≪ 90 and a good upper bound otherwise. Press Run Monte Carlo to see the empirical curves alongside.

Expected first-win round

Using the survival representation for a nonnegative integer random variable:

E[K_T] ≈ Σ_{k=0}^{89} (1 − P_T(k)) plus a small tail for k ≥ 90

Monte Carlo

Each trial draws N independent random plates (each = a random 15-subset of {1,…,90} split into three rows of 5), then a random permutation of 1–90, and records the first round at which any plate hits each tier. This treats plates as iid 15-subsets — the same independence assumption as above — so it cross-checks the closed form rather than capturing correlation from a real plate-generation algorithm.
